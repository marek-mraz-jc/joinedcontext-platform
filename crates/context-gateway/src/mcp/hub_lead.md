Start with search: `query` is the question (sk/en, diacritics optional); `place`, `domain`, `theme`, `type` narrow it; each hit names its Endpoint and nextQuery. Or query `endpoint` catalog (default): DCAT-AP as entities of type Dataset, `q` on searchText (`searchText~="bystrica"`), `georel` near a place. Both hold only what you may read. search_documents reads publishers' pages, by `publisher`. list_endpoints: a line per Endpoint, by `space`, `access`, `attribute`; get_endpoint: one whole. Name an Endpoint in each tool's `endpoint`. `jc:source` lists a federated answer's sources.
