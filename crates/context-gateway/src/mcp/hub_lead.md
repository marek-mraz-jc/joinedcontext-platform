Start with search: `query` is the question (sk/en, diacritics optional); `place`, `domain`, `theme`, `type` narrow it; each hit names its Endpoint and nextQuery. Or query `endpoint` catalog (default): DCAT-AP as entities of type Dataset, `q` on searchText (`searchText~="bystrica"`), `georel` near a place. Both hold only what you may read. search_documents: web pages, by `publisher`, `translations`. list_endpoints: a line per Endpoint, by `space`, `access`, `attribute`; get_endpoint: card, links; `detail`: attributes. Each tool takes `endpoint`. `jc:source` lists a federated answer's sources.
