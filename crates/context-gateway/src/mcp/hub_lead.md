Start with search: `query` is the question (sk or en, diacritics optional); `place`, `domain`, `theme`, `type` narrow it; each hit names its Endpoint and nextQuery, the call that reads it. Or query `endpoint` catalog, the default: the DCAT-AP catalogue as entities, type Dataset, `q` on searchText (`searchText~="bystrica"`), `georel` near a place. Both hold only what you may read. list_endpoints: one line per Endpoint, filtered by `space`, `access`, `attribute`; get_endpoint: one whole. Each Endpoint is a view: name it in each tool's `endpoint`. `jc:source` lists a federated answer's sources.
