# User Guide Overview

Welcome to the **joinedcontext User Guide**. This documentation provides non-technical and technical team members with step-by-step instructions for managing organisational data, pipelines, dashboards, and automated AI workflows.

---

## 1. The joinedcontext Philosophy

joinedcontext eliminates complex command-line overhead in favor of a modern, intuitive management experience:

- **Visual Self-Service:** Data Stewards and Architects configure spaces, models, and dashboards through interactive forms and visual builders.
- **GitOps Under the Hood:** Every button click, form submission, and approval compiles into versioned, reviewable code in the background. You gain full disaster recovery and auditability without needing to memorize Git commands.
- **Native AI Collaboration:** Autonomous AI agents collaborate as first-class team members, operating within strict security sandboxes and submitting proposals through the same review lanes used by human engineers.
